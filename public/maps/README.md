# Parish light map

Adapted from OpenFreeMap Liberty: https://tiles.openfreemap.org/styles/liberty
Upstream project: https://github.com/hyperknot/openfreemap-styles

Changes: warm light surfaces, soft blue water and green parks; less saturated main roads; no buildings, POIs, airport detail, road shields, or rail hatching. Neighborhoods stay visible; major road names start at vector zoom 15, minor streets at 17. Water labels start at 15. City labels end at 13. Leaflet zoom is one level above the vector renderer's zoom because their tile sizes differ.

Style code/design licenses are included in OPENFREEMAP-LICENSE.md and LIBERTY-LICENSE.md. OpenFreeMap, OpenMapTiles, and OpenStreetMap attribution stays visible on the map. Tile and font data continue to load from OpenFreeMap; no API key is used. The local style is versioned so visual changes remain under application control.
